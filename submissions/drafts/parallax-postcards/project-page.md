# Parallax Postcards

**Short description:** Three rooms. Three impossible pictures. One small change of perspective.

Walk through three quiet first-person observation rooms, read a letter, and find the place where scattered fragments become a house, a paper boat and a lantern. The pieces exist at different depths: moving changes their relative size and position. Find the brass cross, turn as the letter suggests, and capture an aligned picture.

Each postcard opens the next room. All three finish the journey, and each collected picture can be downloaded as an original self-contained SVG. There is no time limit, jump scare or failure timer.

## Controls

W/S or up/down arrows move; A/D strafe; left/right arrows turn. Hold Shift while turning for fine adjustment. Drag the view horizontally to look without pointer lock. E reads a nearby letter; Space captures. Screen buttons support touch and holding to move. Undo, Reset position, three-level hints and an optional survey map are available.

## About this build

The primary experience is first person. The world is rendered with an independently written Canvas2D software raycaster, so it does not require WebGL or pointer-lock permission. All visual geometry and letters are local; no account, model API or asset download is required. Browser saves are convenience progress, not an authenticated score.

Code, prose, level geometry, procedural art and documentation were developed with Codex assistance. No generative model runs during play. See the separate AI disclosure.
