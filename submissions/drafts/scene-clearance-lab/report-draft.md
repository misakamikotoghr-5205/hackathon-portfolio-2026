# 留白实验室：生成资产的布置、间距与方案复核

这是可转为项目报告的正文，不是已上传的 PDF/PPT。作者/团队真实信息由本人在正式材料中补入；当前不捏造生成记录或截图。核查日期 2026-11-06。

## 问题与用户

个人创作者得到一个3D模型后，仍需知道这版如何摆放、单位是否一致、两件物品的代理边界是否重叠、A/B方案是否用相同参数比较。仅预览模型难以留下可复核的决定依据。本项目聚焦小型展陈和个人布置排练，不替代专业设计、法规或安全审查。

## 已实现工作流

1. 载入本地静态、未压缩、内嵌缓冲的受支持 glTF/GLB；外部 URI、压缩/蒙皮等不支持内容明确拒绝。
2. 记录原文件 SHA-256 和手动单位覆盖。数据在浏览器本地处理，来源声明仍是用户自述，不能作为平台证明。
3. 调整 X/Z、旋转和尺度；计算定向包围矩形的重叠、最近间距、房间越界与留白带提醒。
4. 保存 A/B 快照，检查参数一致性，再导出带位置、资产指纹、逐对距离与限制的报告。

## 当前证据与真实缺口

程序展厅和测试物件为本项目原创几何；Three.js/OrbitControls是真实开源复用。16项本地测试与构建验证已记录。浏览器环境曾缺 WebGL2，已验证可用俯视降级，不把降级画面冒充完整WebGL实测。

尚无 Lux3D 生成、实际平台导出或现场导入证据。正式交件前需要真正完成：以合法账号生成核心物件 → 保存真实生成/迭代画面与授权 → 导出文件 → 在当前支持的格式/单位范围内实际导入 → 布置并输出方案A/B。若导出不兼容，应报告并修正实现，而不是替换成程序模型声称成功。

## 方法限制与第三方使用

检查只适用于水平地面物件的保守包围矩形，可能对凹形/枝叶空隙误报；不是实际网格碰撞或通行证明。示例距离不是法规阈值。导入不保留纹理保真、动画或全部glTF扩展。本工具不宣称首创模型预览或碰撞检测。
